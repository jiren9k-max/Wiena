Admin panel

Ovo je demo verzija shopa. Admin panel radi u punoj verziji (na serveru) i uključuje:

  • Narudžbe sa statusima, emailom kupcu, štampom i izvozom u Excel
  • Proizvode na bosanskom i engleskom: cijene (KM / €), zalihe, veličine, boje, slike, akcije
  • Kategorije, vaučere, kupce, poruke i newsletter
  • API i webhookove za knjigovodstvo i druge programe
  • Dnevnik izmjena, backup i postavke
